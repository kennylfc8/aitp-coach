# Разметка матча по видео — шаблон

Смотри видео, ставь на паузу после КАЖДОГО проигранного очка, добавляй строку.
Виннеры соперника тоже пиши (одной буквой) — чтобы посчитать их долю, но не разбирать.

## Коды (чтобы писать быстро)

| Ось | Коды |
|-----|------|
| Исход | `W` виннер соперника · `F` вынужденная · `U` невынужденная |
| Удар | `SRV` подача · `DF` двойная · `RET` приём · `FH` форхенд · `BH` бэкхенд · `VOL` слёт · `SM` смэш · `DROP` укороченный |
| Куда | `NET` в сетку · `LONG` аут по длине · `WIDE` аут по ширине |
| Фаза | `S1` подача+1 · `R1` приём+1 · `К` короткий (≤4) · `С` средний (5–8) · `Д` длинный (9+) |
| Причина | `Т` техника · `ТК` тактика · `Ф` физика · `Г` голова |

## Лог (пример первых строк)

| # | Счёт | Исход | Удар | Куда | Фаза | Причина | Заметка |
|---|------|-------|------|------|------|---------|---------|
| 1 | 0:0 15-30 | U | DF | NET | S1 | Г | вторая подача зажался |
| 2 | 0:1 30-30 | U | FH | LONG | С | Т | плоско, без вращения |
| 3 | 0:1 30-40 | F | BH | WIDE | Д | — | вытянули кроссом |
| 4 | ... | | | | | | |

## Сводка после разметки (посчитать)

- Всего проиграно очков: __
- Из них: виннеры соперника __ % · вынужденные __ % · **невынужденные __ %**
  (норма для полупро: UE ≈ 30–40%; если > 50% — матч отдан своими руками)
- Топ-3 корзины UE (удар × куда × фаза): 1) ______ 2) ______ 3) ______
- Двойных ошибок: __ (сколько геймов это стоило?)
- UE на важных очках (30-30, БП, ГП): __ из __ — если доля выше обычной → «голова»
- Серии по 2–3 UE подряд: __ раз (тильт-маркер)

## Что делать с итогом

Топ-3 корзины дают ~80% потерь. На каждую — один дрилл на неделю.
Пример: «U-FH-LONG-С-Т» → форхенд-кросс с запасом 1.5 м над сеткой, 20 мячей серия,
считать % попаданий, цель 85%.
